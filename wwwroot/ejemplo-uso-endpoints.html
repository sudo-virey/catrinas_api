🔐 Sistema de Endpoints Diferenciados por Tipo de Usuario

⚠️ IMPORTANTE: Los endpoints están protegidos por JWT y Role-based Authorization. Cada tipo de usuario solo puede acceder a SUS endpoints específicos.

👨‍💼 Panel ADMINISTRADOR

Rol requerido: "Administrador"

GET /api/admin/dashboard

Datos completos de administración del concurso

Estructura de Respuesta Admin:

{
  "votacionEnCurso": { participante, tiempo... },
  "participantes": [{ id, nombre, estado, orden }],
  "ranking": [{ puntaje, detalles completos }],
  "ajustes": { tiempoVotacion, terminado }
}

🗳️ Panel VOTANTE

Rol requerido: "Publico" + AccessType: "Votacion"

GET /api/votante/dashboard

Datos limitados apropiados para votantes

Estructura de Respuesta Votante:

{
  "concursoTerminado": boolean,
  "votacionEnCurso": boolean,
  "detallesVotacionEnCurso": { participante actual },
  "ranking": [{ solo si terminó concurso }]
}

🛡️ Seguridad Implementada:

  • JWT Token requerido en todas las peticiones
  • Role-based Authorization: [Authorize(Roles = "Administrador")] vs [Authorize(Roles = "Publico")]
  • Validación adicional en el código del endpoint
  • Respuestas completamente diferentes según el tipo de usuario
  • Impossibilidad de cross-access: Un admin no puede acceder a endpoints de votante y viceversa
